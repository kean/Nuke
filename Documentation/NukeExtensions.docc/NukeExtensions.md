# ``NukeExtensions``

Nuke provides convenience extensions for image views with multiple display options.

## Overview

> Warning: `NukeExtensions` is soft-deprecated. Use `ImageLoader` from NukeUI instead: `ImageLoader.load(url, into: imageView)` replaces `loadImage(with:into:)`, and `ImageLoader.Presentation` replaces ``ImageLoadingOptions``. The extensions keep working, and the [migration guide](https://github.com/kean/Nuke/blob/main/Documentation/Migrations/Nuke%2014%20Migration%20Guide.md) maps their options to the new API.

In this guide, you'll learn about these extensions and all of the available options.
