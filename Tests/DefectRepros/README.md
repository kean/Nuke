# Defect repros

Found on 2026-09-19 while extending the test coverage, against `2c2b23f6` (PR #975). Every `.swift` file in this folder is a Swift Testing suite that **fails on that code**. The folder belongs to no target on purpose, so the suites stay green. To reproduce one, copy it into the test target folder it sits under and run it alone:

```sh
cp Tests/DefectRepros/NukeTests/memory-cache--new-entry-evicts-itself.swift Tests/NukeTests/
xcodebuild test -project Nuke.xcodeproj -scheme Nuke -destination 'platform=macOS' -only-testing:NukeTests/<SuiteName>
```

Use the `Nuke` scheme for `NukeTests/`, `NukeUI` for `NukeUITests/` and `NukeThreadSafetyTests` for `NukeThreadSafetyTests/`. The last one needs `CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO CODE_SIGN_IDENTITY=""` on macOS. Run `NukeVideoTests/` with `swift test --filter <SuiteName>`. Each file names its expected and actual behavior in its header comment. Some UIKit repros only compile for iOS and tvOS. Some suites share private helper names, so drop them in one at a time.

**How each finding was checked.** A test-writing agent found the bug and wrote the repro. An adversarial reviewer checked the repro for test mistakes. Then two independent checks:

- A second agent re-ran the repro three times in a clean checkout and checked the stated root cause in the source.
- A third agent tried to argue that the behavior is intended, documented, or not reachable through public API.

Each finding has one of three statuses:

- **Confirmed:** it reproduced every time, the test is sound, and the refutation failed.
- **Rejected:** it reproduced, but the refutation succeeded (intended, documented, or not reachable from public API). It's kept because the behavior is real.
- **Unverified:** found by the decoding, video and concurrency writers, whose review was cut off. Each still has a repro that failed when the writer ran it, but nothing checked it independently.

Findings reported by more than one area are merged. "Known #n" points to an entry in `~/Documents/_nuke/defects.md`, the 2026-08 review, and means that defect is still present. Full details for each finding (reproduction evidence, the refutation attempt, a suggested fix) are in [DETAILS.md](DETAILS.md).
